# Dissent Log

*For The Constitution of Co-existence and The Service Charter under it.*
*Canonical: <https://coexist.humanhighway.net/dissent>. Public domain (CC0-1.0).*

This file is empty on purpose. It is the place for public disagreement with the
constitution, the charter, or the implementation that claims to enforce them, and its
emptiness at publication is a fact about how new the documents are, not about how right
they are. A constitution that values dissent has to keep a room for it before anyone
arrives.

## How to file

Open a pull request or an issue against
<https://github.com/Capitali/familiar/tree/main/data/laws>, or write to
<coexist@humanhighway.net>. A dissent is recorded here verbatim, attributed as its author
chooses, with the date and the version it answers. It is never edited by the authors of
the documents it disputes, and it is never removed; a dissent later answered gets an answer
beneath it, not a deletion.

One entry per dissent, newest on top:

```
## YYYY-MM-DD — <one line naming the disagreement>
- answers: constitution v1 | charter v1 | red-team Qn | implementation
- by: <name, handle, or "anonymous">
- text: <verbatim>
- answer: <if any, dated and signed>
```
